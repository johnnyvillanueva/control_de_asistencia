Cómo editar la lista de alumnos
  1. Abre el archivo alumnos.json con el Bloc de notas (clic derecho → Abrir con).
  2. Cambia los nombres dentro de las comillas. Cada alumno va entre " " y separado por una coma. Respeta la coma final del último nombre anterior.
  3. Guarda el archivo con codificación UTF-8.
  4. Abre lista.html y pulsa Cargar alumnos.json (también puedes arrastrar el archivo sobre la página). La lista queda recordada en este navegador.

La lista siempre se muestra en orden alfabético (por apellido), sin importar el orden en que estén escritos los nombres en el archivo.

Consejo: si guardas los dos archivos en una carpeta y abres la página desde un servidor local (por ejemplo python -m http.server), la lista se carga sola y los cambios se ven al recargar.
